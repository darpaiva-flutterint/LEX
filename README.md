## LEX (Log Extractor) is used to copy logs from Network directories and paste them on your local computer.

## Needed to run the application:
- Windows 10 or above.

## Needed to build the application:
- Visual Studio
- .NET Framework 4.7.2 or above

- The application is created with C# without the use of any additional Frameworks.
- The GUI of the application is created using Windows Forms.
